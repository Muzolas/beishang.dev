# beishang.dev

Muzaffer Beysan Kalem — Kişisel Portfolyo & Web Sitesi

Modern web teknolojileri ve Next.js ile geliştirilmiş kişisel portfolyo projesi.

## Geliştirme

```bash
# Bağımlılıkları yükleyin
pnpm install # veya npm install

# Geliştirme sunucusunu başlatın
pnpm dev # veya npm run dev
```

## Telemetri & Canlı Dağıtım
Bu proje, **NexusApp (ICC)** üzerinden CI/CD iş akışları, Vercel dağıtımları ve sürüm kapıları ile uçtan uca izlenmektedir.
